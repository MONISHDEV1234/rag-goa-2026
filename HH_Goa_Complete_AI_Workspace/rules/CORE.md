# CORE RULES

- Inspect before modifying.
- Follow `README.md` for project requirements.
- Respect role ownership.
- Keep changes focused.
- Never fabricate evidence.
- Never expose secrets.
- Test relevant changes.
- Append progress after meaningful work.
- Historical progress is immutable.
- Existing-feature changes require a new history entry explaining what and why.
- Report blockers rather than guessing.
