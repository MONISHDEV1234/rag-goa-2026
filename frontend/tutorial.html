System User Guide

Follow these steps to query the SONAR voice neural retrieval system, inspect retrieved knowledge chunks, verify source citations, and monitor latency metrics.

STEP 01

Voice Recording or Text Query

Click the large Microphone Button in the center to begin speaking your question in English or Indian languages. When finished, tap it again to stop. Alternatively, you can type your query in the terminal input bar or tap any of the quick-launch suggestion chips (RAG, FAISS, CHUNKING, LATENCY).

STEP 02

Live Pipeline Status Monitoring

Watch the real-time status ticker transition through each neural stage:
STT TRANSCRIBING → FAISS SEARCHING → LLM GENERATING → GROUNDING CHECK.

STEP 03

Grounded Answer & Citations

The system displays a high-accuracy answer along with a ✓ Grounded verification badge. Below the answer card, you can inspect the retrieved document nodes, chunking strategy used, and vector cosine similarity scores. Use the SPEAK button to read answers aloud via Web Speech synthesis.

STEP 04

Latency Telemetry & Demo Mode

Examine the Latency Telemetry panel to see exact milliseconds spent on STT, embedding, retrieval, and generation against our <200ms target. Tap the ⚙ SYS button in the top header to toggle Demo Mode or adjust Top-K document retrieval.
