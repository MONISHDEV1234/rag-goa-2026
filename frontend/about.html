ABOUT THE PLATFORM

What is SONAR?

SONAR — SOund Neural Answer Retrieval — is an ultra-low latency, voice-first Retrieval-Augmented Generation system built for HH Goa 2026 Task 2. It bridges multilingual Indian-accent speech transcription with in-memory dense vector search and Groq LPU hardware inference to answer queries in under 200ms.

Sarvam AI Saarika v2.5 FastEmbed MiniLM-L12 Hybrid BM25 + FAISS RRF Groq LPU Inference Multilingual Grounding Guard
01

AudioWorklet PCM Capture & Multi-Device Toggle

Raw microphone audio is captured in real-time using high-precision AudioWorklet PCM processing with a 16-bit 48kHz WAV encoder and browser Web Speech APIs. Users can seamlessly toggle between Earphone, Headset, and Array microphones with instant live sample telemetry.

02

Multilingual Neural Speech-to-Text (ASR)

Audio streams directly to Sarvam AI's saarika:v2.5 endpoint via persistent async httpx connections and Tenacity retries, supporting automatic language identification and Indian-accent English, Hindi, and regional Indic languages.

03

Multilingual Dense Vector Embedding

Incoming queries are encoded into 384-dimensional normalized dense vectors using sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2 via in-process ONNX Runtime (~15ms), enabling cross-lingual semantic alignment across Indic languages and English.

04

Hybrid Sparse (BM25) + Dense (FAISS) Reciprocal Rank Fusion

Queries search across 7,650+ indexed multilingual chunks using FAISS IndexFlatIP dense search combined with BM25 sparse keyword matching. Reciprocal Rank Fusion (RRF) merges top candidates in < 1ms with high keyword and semantic precision.

05

Groq LPU Hardware Generation

Retrieved context and user queries are passed to Groq LPUs running openai/gpt-oss-20b in strict structured JSON mode at over 700 tokens per second, ensuring verifiable fact synthesis.

06

Cross-Lingual Grounding & Citation Verification

Deterministic grounding filters verify that every generated response fact is grounded in the retrieved sources, supporting cross-lingual reasoning from Indic passages to English answers with source citation chips and TTS speech playback.
