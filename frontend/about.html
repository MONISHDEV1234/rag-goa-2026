ABOUT THE PLATFORM

What is SONAR?

SONAR — SOund Neural Answer Retrieval — is an ultra-low latency, voice-first Retrieval-Augmented Generation system built for HH Goa 2026 Task 2. It bridges multilingual Indian-accent speech transcription with in-memory dense vector search and Groq LPU hardware inference to answer queries in under 200ms.

Sarvam AI STT FastEmbed FAISS IndexFlatIP Groq LPU MSMARCO-XI
01

Audio Stream Ingestion & Preprocessing

Raw browser microphone input is captured via MediaRecorder API using WebM/Opus encoding at 16kHz mono. Audio chunks are dispatched asynchronously with minimal protocol overhead.

02

Multilingual Neural Speech-to-Text

Audio streams directly to Sarvam AI saarika:v2.5 endpoint via persistent async httpx connections and Tenacity retry handlers. Completes in ~60ms with automatic language identification for Indian accents.

03

Dense In-Process Vector Embedding

Incoming queries are encoded into 384-dimensional dense vector embeddings using BAAI/bge-small-en-v1.5 via ONNX runtime in-process (~9ms), avoiding external network round-trips.

04

In-Memory FAISS Vector Retrieval

Queries are searched against millions of pre-indexed AI4Bharat MSMARCO-XI chunks held in RAM using FAISS IndexFlatIP. Candidate passages are cosine-ranked in ~5ms across 3 chunking strategies.

05

Groq LPU Hardware Generation

Retrieved passages and user queries are passed to Groq LPU running llama-3.1-8b-instant with strict prompt grounding constraints. Answers are synthesized in ~75ms.

06

Hallucination Guard & Citation Verification

The safety verification engine cross-references synthesized answer claims against retrieved source chunk tokens, stamping verified responses with a ✓ Grounded badge and document citation tags.
