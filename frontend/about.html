// SYSTEM ARCHITECTURE & PROJECT BRIEF

SOund Neural Answer Retrieval

SONAR is an ultra-low latency, voice-first Retrieval-Augmented Generation (RAG) system built for HH Goa 2026. It merges multilingual Indian-accent speech recognition with high-density vector retrieval and Groq LPU inference to deliver grounded answers under 200 milliseconds.

PIPELINE STAGE 01

Sarvam STT Engine

Captures raw browser audio using MediaRecorder (WebM/Opus) and transcribes with Sarvam AI's saarika:v2.5 endpoint in ~60ms with Indian-language and accent optimization.

PIPELINE STAGE 02

FAISS Neural Retrieval

Queries embedded via FastEmbed BGE-small-en-v1.5 in ~9ms. Retieved from in-memory FAISS IndexFlatIP index against AI4Bharat MSMARCO-XI dataset in <5ms.

PIPELINE STAGE 03

Groq LPU Generation

Generates grounded answers via llama-3.1-8b-instant with strict citation constraints in ~75ms. Guardrails verify factuality against retrieved passages.
