SYSTEM CAPABILITIES

🎙
STT ENGINE

Voice-First Input

Browser MediaRecorder captures audio in WebM/Opus. Sarvam AI saarika:v2.5 transcribes multilingual speech with Indian-accent optimization in under 60 ms.

~60 ms avg transcription
🧩
CHUNKING

Triple Chunking

Three strategies running on MSMARCO-XI: Semantic (embedding boundary detection), Sliding-Window (overlapping tokens), and Metadata-Aware (preserving doc provenance).

3 strategies benchmarked
⚡
FAISS

In-Memory Vector Search

FAISS IndexFlatIP loaded entirely in RAM at startup. Cosine similarity over BAAI/bge-small-en-v1.5 FastEmbed vectors. Zero disk I/O per request.

~5 ms avg retrieval
🤖
LLM

Groq-Powered Generation

Groq LPU serves llama-3.1-8b-instant at hardware speed. Prompt capped at 512 tokens, output at 256 tokens. Single LLM call — no chained generation.

~75 ms avg generation
🛡
GUARDRAILS

Multi-Layer Safety

Input guard rejects off-topic and unsafe queries. Similarity threshold refuses LLM calls when context is insufficient. Grounding checker validates every answer against retrieved passages.

4 guard layers
📊
BENCHMARKS

Real Latency Analytics

100-query benchmark suite measuring per-stage latency (STT, embedding, retrieval, generation, grounding). Reports P50 / P70 / P100 percentiles. No fake numbers.

P50/P70/P100 reported
